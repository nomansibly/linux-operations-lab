Reproduce the complete demonstration

python3 scripts/complete_demo.py

One command runs unit tests, starts and stops the isolated service, checks failure and recovery, verifies SQLite output and regenerates this page. No pip dependencies or database server required. Linux and Python 3.10+ are required.

Engineering choices

Diagnose before restarting

A refused connection, HTTP 404 and HTTP 503 describe different failure layers. Each case records the symptom, targeted fix and successful HTTP check.

Unknown stays unknown

A missing service response does not become a healthy reading. CPU intervals with no elapsed ticks remain unknown. Metrics and application health are evaluated separately.
